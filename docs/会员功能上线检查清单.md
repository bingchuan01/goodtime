# 会员功能上线检查清单

会员相关改动分 **小程序前端** 与 **Node 后端（ECS）** 两条线，勿混用「上传」传后端。

---

## 一、职责划分

| 内容 | 做法 | 不要 |
|------|------|------|
| `pages/`、`utils/`、`components/`、`images/` 等 | 微信开发者工具 **编译 → 上传/预览** | 指望上传打包 `server/` |
| `server/lib/member-active.js`、`server/routes/*.js` 等 | 本机 **scp → ECS** + **`pm2 reload`** | 上传到微信小程序后台 |

`project.config.json` 已配置 `packOptions.ignore: server`，上传成功若提示「若干 server 文件未打包」**属正常**。

## 二、后端（阿里云 ECS）

### 2.1 本机 PowerShell（勿在 ECS 里 scp）

```powershell
$KEY = "C:\path\to\你的密钥.pem"
$ECS = "ecs-user@你的公网IP"
$REMOTE = "/home/ecs-user/goodtime/server"

scp -i $KEY "E:\goodtime\server\lib\member-active.js" "${ECS}:${REMOTE}/lib/"
scp -i $KEY "E:\goodtime\server\lib\member-catalog.js" "${ECS}:${REMOTE}/lib/"
scp -i $KEY "E:\goodtime\server\lib\member-order-paid.js" "${ECS}:${REMOTE}/lib/"
scp -i $KEY "E:\goodtime\server\routes\projects.js" "${ECS}:${REMOTE}/routes/"
scp -i $KEY "E:\goodtime\server\routes\user.js" "${ECS}:${REMOTE}/routes/"
scp -i $KEY "E:\goodtime\server\routes\member.js" "${ECS}:${REMOTE}/routes/"
scp -i $KEY "E:\goodtime\server\routes\member-catalog.js" "${ECS}:${REMOTE}/routes/"
scp -i $KEY "E:\goodtime\server\routes\config.js" "${ECS}:${REMOTE}/routes/"
scp -i $KEY "E:\goodtime\server\routes\admin.js" "${ECS}:${REMOTE}/routes/"
scp -i $KEY "E:\goodtime\server\middleware\auth.js" "${ECS}:${REMOTE}/middleware/"

```

按本次改动增减文件；`pm2 show goodtime-api` 的 **exec cwd** 即为 `$REMOTE`。

### 2.2 ECS 终端

```bash
grep -n "reconcileExpiredMembership\|reconcileAllExpired" /home/ecs-user/goodtime/server/lib/member-active.js
cd /home/ecs-user/goodtime/server
pm2 reload goodtime-api --update-env
pm2 list
```

`goodtime-api` 为 **online** 即可。

### 2.3 服务端行为（到期自动降级）

- `member_expire_time` 已过期且仍为 V6/V8 → 写库 **`member_level` 置空**（保留到期日供续费叠加与展示）。
- 触发时机：服务启动批量扫描、鉴权 `auth`、登录/`/user/info`、`/member/info`、发布接口校验前。

## 三、小程序前端

涉及页面：`pages/user/profile/`、`pages/member/benefits/`、`pages/member/upgrade/`、`utils/api.js`。

1. `utils/api.js` → `ENV = 'prod'`（测线上）。
2. 保存后 **编译**。
3. **上传** 或 **预览**（预览旁标「开发版」正常；上传后可在公众平台用体验版扫码）。
4. 真机验收建议顺序：
   - **未登录**：个人中心见「登录/注册 · 未登录」；会员中心点「立即开通」应提示登录。
   - **已过期会员**：退出登录 → 再登录（拉取降级后的 `member_level`）；会员中心仅显示到期日，无 V6/V8 角标。
   - **支付页**：V6/V8 划线价；体验卡活动截止时间与背景图与后台一致。

---

## 四、建议验收项

| 场景 | 期望 |
|------|------|
| V6/V8 且未过期 | 会员中心显示等级与有效期；可发布（若权益允许） |
| 已过期 | 会员中心**不**再显示 V6/V8 标签；文案「会员已于 xxx 到期」（无「请续费」）；**不可发布**；接口 403 |
| 未登录点开通 | 会员中心/支付页拦截并引导登录 |
| 支付页 V6/V8 | 原卡片样式 + **划线价**（无活动结束时间） |
| 体验优惠卡 | 独立卡片：划线价 + 活动结束时间 + 可换背景图；后台「体验会员限时优惠卡」配置 |
| 体验优惠卡支付 | 开通后身份为 **体验者**（非 V6），体验有效期内可发布 |
| 发布 Tab | 未登录 / 非会员 / 已过期每次进入 `onShow` 均拦截 |
| 续费成功 | `member_level` 恢复；`member_expire_time` 按规则延长 |
| 非会员 | 「尚未开通」；发布引导开通/联系客服 |

## 五、常见问题

- **上传后 58 个 server 文件未打包**：正常，后端只走 scp。
- **pm2 online 但仍显示 V6 已过期**：未传最新 `user.js`/`member-active.js`，或未重新登录。
- **只预览未上传**：可测前端；与上传/体验版包版本可能不一致。
