# 问题解决记录

## 真机详情页首次加载失败（2025-03）

### 问题描述

- **现象**：真机点击项目卡片后，先出现「加载失败」页，需返回再点一次才能看见详情
- **环境**：开发者工具正常，真机调试/体验版复现
- **用户反馈**：点击两次返回才能看见详情页

### 根因分析

详情页首次进入时发起 API 请求，真机环境下网络连接可能尚未就绪，导致首次请求失败。

### 解决方案：首页预取

**思路**：在已建立连接的首页发起详情请求，成功后再跳转，避免在新页面首次请求。

**实现要点**：

1. **app.js**：增加 `globalData.prefetchedProject` 用于传递预取数据
2. **pages/index/index.js**：点击卡片时先请求详情，成功后再 `wx.navigateTo`
3. **pages/video-detail/video-detail.js**：`onLoad` 优先检查 `prefetchedProject`，有则直接使用，无则调用 `loadProjectDetail`

**相关修改**：

- `showContent` + 350ms 延迟：避免过渡动画期间底部详情图闪现
- `applyProjectData`：统一处理项目数据的应用逻辑

### 涉及文件

| 文件 | 修改内容 |
|------|----------|
| app.js | globalData.prefetchedProject |
| pages/index/index.js | onProjectTap 改为先请求再跳转 |
| pages/video-detail/video-detail.js | 预取数据读取、showContent、applyProjectData |

### 回滚方式

回退到修复前的状态（标签 fix-detail-prefetch 的上一提交）：

```bash
git checkout fix-detail-prefetch~1 -- app.js pages/index/index.js pages/video-detail/video-detail.js pages/video-detail/video-detail.wxml pages/video-detail/video-detail.wxss
```

或回退整个项目到修复前：

```bash
git log --oneline -3  # 查看提交历史
git reset --hard fix-detail-prefetch~1
```

## 开屏页顶部/底部深色条、图片未铺满（2025-03）

### 问题描述

- **现象**：开屏页（引导页）顶部（胶囊上方）与底部出现深色条，或整块背景为深色，开屏图未完整铺满一屏
- **环境**：微信小程序，含 Skyline 渲染；`navigationStyle: custom` 无原生导航栏
- **尝试过但无效或适得其反**：用 `padding-top: safeTop` 留出状态栏、用 `screenHeight - safeTop` 算图片高度、给页面/容器设深色背景「与图片底部一致」、设为透明（`backgroundColor: "transparent"` 在 json 中不支持会报错）

### 根因简述

- 页面可绘制区域与安全区/视口关系因机型与 Skyline 存在差异，用固定数值或留白容易在顶部/底部露出容器或页面背景色。
- 若容器有 `background: #xxx` 且图片未在布局上完全覆盖容器，就会看到上下两条「背景色条」。

### 解决方案：图片绝对定位铺满容器 + 容器背景透明

**思路**：不依赖 `padding-top`/`safeTop` 或固定高度计算，让开屏图在布局上完全覆盖整屏容器，且容器背景透明，这样不会露出任何深色条。

**实现要点**：

1. **容器（.container）**
   - `position: fixed; left: 0; top: 0; right: 0; bottom: 0;` 占满视口，不再写死 `height: {{screenHeight}}px`。
   - `background: transparent`，避免任何未覆盖区域显示为深色。

2. **开屏图（.splash）**
   - `position: absolute; top: 0; left: 0; right: 0; bottom: 0; width: 100%; height: 100%;`，相对容器绝对定位并铺满，不依赖内联 `height`。
   - `mode="aspectFill"` 保持比例铺满，多余裁剪。

3. **WXML**
   - 容器不再写 `padding-top`、不再写内联 `height`；图片不再写内联 `style="height: ..."`。

4. **页面配置**
   - 若此前为「与图片底部一致」在 `guide.json` 中设置了 `backgroundColor`，可保留或移除，不影响最终效果；页面背景仅在图片未覆盖的极边缘或加载前可能露出。

### 涉及文件

| 文件 | 修改内容 |
|------|----------|
| pages/guide/guide.wxss | .container 使用 fixed 占满 + background: transparent；.splash 使用 absolute + top/left/right/bottom: 0 + width/height: 100% |
| pages/guide/guide.wxml | 去掉容器的 padding-top、height 内联；去掉图片的 height 内联 |
| pages/guide/guide.js | 可不再 setData screenHeight/imageHeight（若 wxml 已不引用） |

### 同类问题优先执行

**遇到「开屏/引导页顶部或底部出现色条、图片未铺满」时，优先：**

1. 容器 `position: fixed` 占满视口，`background: transparent`。
2. 开屏图 `position: absolute` + 四边 0 + `width/height: 100%`，`mode="aspectFill"`，不依赖 safeTop/screenHeight 的内联高度。

## 首页数据看板对齐 + 新增分类图标风格统一（2026-04）

### 问题描述

- **现象1**：首页数据看板存在对齐偏差，文本标签与数值在不同项之间出现基线不齐。
- **现象2**：首页新增 9 个分类后，图标样式与原有「热门/趋势/上新」风格不统一。

### 处理结果

1. **数据看板对齐修复**
   - 保持「标签一行、数值一行」的展示结构。
   - 去除 `info-row` 并为 `label/value` 设置统一高度与行高，确保横向对齐。
2. **新增分类图标统一**
   - 为 9 个新增分类补齐独立 SVG 图标，风格与现有首页导航图标保持一致。
   - 前端分类映射与后端默认分类图标路径同步更新。

### 涉及文件

| 文件 | 修改内容 |
|------|----------|
| components/data-dashboard/data-dashboard.wxml | 恢复两行结构，移除 `info-row` |
| components/data-dashboard/data-dashboard.wxss | 统一 `label/value` 的高度与行高 |
| utils/categories.js | 新增分类图标路径映射 |
| server/db.js | 后端默认分类图标路径同步 |
| images/icons/health.svg 等 9 个文件 | 新增分类图标资源 |

### 部署说明

- 前端资源变更需重新上传小程序开发版/体验版。
- 云端不可直接 `git pull` 时，可用 `scp + 解压 + cp -f` 覆盖目标文件并重启服务。

### 验收结果

- 手机端已确认 9 个新增分类图标显示成功。
- 数据看板对齐已达到预期。

## 会员到期自动降级与发布拦截（2026-05）

### 问题描述

- 会员 `member_expire_time` 已过期后，库内仍保留 `member_level` 为 V6/V8，会员中心仍展示付费身份，但发布等权益未按会员履约，存在合规与客诉风险。
- 发布页仅校验等级、不校验有效期；服务端创建项目也未校验到期。

### 解决方案

1. **到期自动降级**：`server/lib/member-active.js` 在启动批量扫描、鉴权、`/user/info`、登录归一化等时机，将已过期用户的 `member_level` 置空（保留 `member_expire_time` 供续费叠加与展示）。
2. **发布拦截**：前后端校验有效期内 V6/V8 方可发布；过期返回 403 并引导续费。
3. **前端展示**：`utils/member.js` 的 `isActivePaidMember`；会员权益页到期显示「会员已于 xxx 到期，请续费」，不再展示 V6/V8 标签。

### 上线检查清单

详见 [会员功能上线检查清单.md](./会员功能上线检查清单.md)（**前端上传与后端 scp 分开**）。

### 涉及文件（节选）

| 文件 | 说明 |
|------|------|
| server/lib/member-active.js | 到期判定、降级、发布校验 |
| server/middleware/auth.js | 鉴权时降级 |
| server/routes/user.js、member.js、projects.js | 用户信息、对账、创建项目 |
| utils/member.js、pages/publish/publish.js | 小程序发布与会员态 |
| pages/member/benefits/*、pages/member/center/center.js | 会员中心展示 |
