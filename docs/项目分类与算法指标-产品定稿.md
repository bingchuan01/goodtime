## 一、范围与原则

### 1.1 本期范围

- 首页分类导航尾部 **「全部项目」** → 二级分类（左类右项）
- **热度飙升池**、首页 10 展示、**Top50强** 独立页与二级筛选
- 项目 **卡片 / 详情** 算法指标标签
- **收藏** P0 + 个人中心「我的收藏」

### 1.2 核心原则（防「强者恒强」）

| 原则 | 说明 |
|------|------|
| **数值不参与 Top 排名** | 咨询 / 收藏 / 分享 / 观看 **不决定** 飙升池入选、不决定默认列表排序 |
| **发布时间轮替** | 飙升池与默认列表以 **`published_at`** 为主，让新发布有机会曝光 |
| **人工置顶独立** | **不占** 飙升池 50 席、**不占** 首页 10 席 |
| **指标只供判断** | 数字标签仅帮助用户判断项目受欢迎程度，不参与平台推荐算法（MVP） |

### 1.3 后期预留

- **流动红旗**：月更 + 池内轮替自然形成上榜变化；动效与新上榜提示为 **P2+**，MVP 不做动画。

## 二、「全部项目」二级分类页

### 2.1 入口

- 首页 `components/category-nav` **最右侧** 增加 **「全部项目」**
- 点击 → 新页面（建议 `pages/category/all` 或 `pages/project/category-all`）

### 2.2 交互：左选右显（A）

- **左侧**：一级分组 / 行业（竖向列表）
- **右侧**：当前选中项下的 **二级标签（L3）** 宫格或列表
- 点击 L3 → 项目列表页（`categoryId` + `categoryTag`）
- **品牌上新**：参照文档写明不设二级 → 点击后直接 `displayZone=new` 项目列表

### 2.3 分类数据结构

以 `好时机分类导航二类分类参照文档.txt` 为准：

| 层级 | 示例 |
|------|------|
| L1 | 热门赛道、趋势前沿、品牌上新 |
| L2 | 餐饮美食、教育培训、医美护肤… |
| L3 | 中式快餐、火锅/串串、茶饮/甜品… |

与现网 `categories` 表 / `DEFAULT_CATEGORIES` 做 **id 对照表**（Plan 阶段列出，注意「保健养生」等文案统一）。

### 2.4 色系（个人中心风）

对齐 `pages/user/profile`：**不用**参照图大红渐变条。

| Token | 值 |
|-------|-----|
| 页背景 | `#f5f5f5` |
| 卡片/面板 | `#fff`，圆角约 `10rpx` |
| 主字 | `#333` |
| 辅字 | `#666` / `#999` |
| 分割线 | `#f0f0f0` |
| 左侧选中 | 左细条 + 字重，灰系 |
| 右侧 chip | 浅灰底 / 灰描边 |

**全项目模块中，仅「热度飙升」标签使用橙色（`#FF6B35` 系）**；二级分类页本身不用大面积橙。

### 2.5 二级筛选（与 L3 列表并存）

在项目列表顶栏或二级页提供筛选（可组合）：

| 筛选项 | 选项 |
|--------|------|
| **Top50强** | 当月 **热度飙升池 50**（与 Top50 独立页同数据源） |
| **价格区间** | 1～5 万、6～10 万、11～20 万、21～50 万、50 万以上 |
| **地址** | 项目 IP / 城市 / 地区（与现 `ip`、地区字段对齐） |

- **默认**（未选 Top50）：当前分类下在架项目，**`published_at` 降序**
- 选 **Top50强** 后：在池内 50 个再按价/址缩小；排序仍默认 **`published_at` 降序**

价格区间对接发布页投资额字段（`investmentAmount` / `base_amount` / `max_amount`，Plan 定解析规则）。

## 三、热度飙升池（50）与首页（10）与 Top50强

### 3.1 结构

```
每月 1 日重算（按 published_at 轮替，不用数值）
              ↓
    「热度飙升」池 = 最多 50 个在架项目
              ↓
      ┌───────┴───────┐
      ↓               ↓
  首页 MVP 专区    Top50强 独立页
  展示其中 10 个    列表流展示全部 50 个
      ↓
二级筛选「Top50强」→ 同池 50 个
```

### 3.2 入选规则（每月重算）

| 项 | 规则 |
|----|------|
| 频率 | **每月 1 日** 重算（建议 00:05，服务器时区） |
| 依据 | **`published_at` 降序**，取在架项目前 **50** 名 |
| 数值 | **不使用** 咨询 / 收藏 / 分享 / 观看 |
| 人工置顶 | **不占** 50 席 |
| 月内 | 池内 50 **不变**（除非运营后台干预） |
| 并列第 50 | `published_at` 相同 → **先达到该时间者优先**（或 `project_id` 次序，实现时写死一条） |
| 下月 | 重算轮替，新发布项目有机会入池 |

### 3.3 「热度飙升」标签

| 项 | 规则 |
|----|------|
| 文案 | 固定 **「热度飙升」**（不用「飙升」简写） |
| 样式 | **橙色** `#FF6B35` 系，与其它灰系指标区分 |
| 范围 | 当月入选 **飙升池 50** 的项目 **均带** 此标签 |
| 数字 | 标签上 **不显示具体数值** |

### 3.4 首页 MVP

- 从当月飙升池 50 中，取 **`published_at` 最新的 10 个** 在首页专区展示
- 首页 **仅展示 10 个**，不等于全站只有 10 个带标项目

### 3.5 Top50强

| 项 | 规则 |
|----|------|
| 定义 | **当月热度飙升池 50 个项目**（非运营手工勾选另一套榜单） |
| 独立页 | 新页面，**列表流 + 项目卡片**（复用 `project-card`） |
| 入口 | ① 二级分类/筛选 **「Top50强」**；② 可增首页或分类页入口（Plan 定） |
| 数据 | 与筛选「Top50强」**同一接口 / 同一池** |
| 排序 | 默认 **`published_at` 降序** |

## 四、算法指标（展示用，不参与排名）

### 4.1 四个带数字指标

| 指标 | 展示文案 | 统计口径 |
|------|----------|----------|
| **咨询** | `N人咨询` | 详情 **私信 UV** + **免费获取品牌资料（留资）UV**；**同一用户对同一项目合并计 1** |
| **收藏** | `N收藏` | 收藏 UV（**P0**）；个人中心同步 |
| **分享** | `N分享` | 项目维度分享成功次数（防刷规则 Plan 定） |
| **观看** | `N观看` | **原 `view_count` 逻辑不变**，仅文案由「播放量」改为「观看」= 进入详情/点开次数 |

### 4.2 展示阈值

- 咨询 / 收藏 / 分享 / 观看：**数值 < 15 → 不展示该数字标签**（卡片与详情均适用，详情可对未达标项隐藏或显示「—」，实现时统一一种）

### 4.3 数字格式

示例：`30人咨询`、`1千收藏`、`2万分享`、`1.2万观看`（千/万格式化规则由 Plan 定）。

### 4.4 与飙升池的关系

```
数值标签 → 仅展示，不参与飙升池入选、不参与默认排序
published_at → 飙升池 50、默认列表排序
```

## 五、项目卡片与详情页

### 5.1 卡片 · 算法标签区（总共最多 1 个）

1. **若在当月飙升池 50 内** → **只显示「热度飙升」**（橙色），**不显示** 咨询/收藏/分享/观看任一数值标签。  
2. **若不在池内** → 在咨询 / 收藏 / 分享 / 观看 中取 **数值最高且 ≥ 15** 的 **1 个**；平票优先级：**分享 > 收藏 > 咨询 > 观看**。

### 5.2 卡片 · 布局（已定）

```
[封面]
标题
[IP] [行业标签] [观看 N]          ← info-row 末（原「门店」位）
[会员/认证标签行]
[热度飙升] 或 [2万分享] 等        ← 算法区最多 1 个标签
─────────────────
门店 N              投资额 ¥…      ← footer 左（原「播放量/观看」位）
```

- **观看**：`view_count`，文案「观看」，逻辑与现播放量一致。

### 5.3 详情页

- **不受** 卡片「仅 1 标签」限制
- 可同时展示：**热度飙升**（若在池内）+ 咨询 / 收藏 / 分享 / 观看（各自 ≥ 15）
- 保留「免费获取品牌资料」「私信」等现有能力
- 建议将原「播放」统计区文案同步为 **「观看」**

## 七、列表排序与人工置顶

| 场景 | 默认排序 |
|------|----------|
| 首页瀑布流（非飙升专区） | `published_at` **降序** |
| L3 分类项目列表 | `published_at` **降序** |
| Top50强 页 / Top50 筛选结果 | 池内 `published_at` **降序** |
| 叠加价/址筛选后 | 仍默认 `published_at` **降序** |

**人工置顶**：独立运营位，**不占** 飙升池 50、**不占** 首页 10；列表顶部优先展示。

## 八、后端与数据建议

### 8.1 表 / 字段（建议）

| 名称 | 说明 |
|------|------|
| `category_tags` | L3 标签配置（可 JSON + 后台） |
| `user_favorites` | user_id, project_id, created_at |
| `project_stats` | consult_uv, favorite_uv, share_pv, view_count（逻辑沿用 view_count） |
| `surge_pool` 或项目字段 | `is_in_surge_pool`, `surge_pool_rank`(1～50), `surge_pool_month`(YYYY-MM), `is_home_surge_featured`(是否首页 10) |

### 8.2 定时任务

- **每月 1 日**：按 `published_at` 重算飙升池 50；标记首页 10；写 `surge_pool_month`

### 8.3 接口（建议）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/projects/surge-pool` | 当月池 50（Top50 页 + 筛选） |
| GET | `/projects?featuredSurge=1&limit=10` | 首页飙升专区 10 |
| GET | `/projects` | 扩展：`categoryId`, `categoryTag`, `displayZone`, `priceMin/Max`, `region`, `inSurgePool`, `sort=published_at` |
| GET | `/projects/:id/stats` | 详情四指标 |
| POST | `/projects/:id/favorite` | 收藏 toggle |
| GET | `/user/favorites` | 个人中心收藏列表 |

列表接口返回 `algoTag`（卡片用）与 `stats`（详情用），避免 N+1。

### 8.4 事件埋点

- 进入详情 → `view_count` +1（逻辑保持）
- 私信发起、留资提交、收藏、分享成功 → 更新 `project_stats`
