## 一、机制总览（经验 + 积分双轨）

| 维度 | 经验（EXP） | 积分（POINTS） |
|------|-------------|----------------|
| 作用 | 决定 **Sv1～Sv13**，解锁发布权、展示期延长、徽章 | **可消耗货币**，兑换商城商品/权益卡 |
| 数量变化 | **只增不减**（见 [确认清单 #1](#确认清单)） | **可增可减**（获得、兑换、过期扣减） |
| 与付费会员 | 1.2 倍获取系数 | 建议 1.2 倍获取系数（与经验一致） |
| 用户感知 | 成长 / 等级 / 身份 | 福利 / 兑换 |

**捆绑原则**

1. 同一行为双轨发放：签到、分享、拉新等 → EXP（×角色系数）+ 积分（×角色系数 × Sv 加成）。
2. 等级反哺积分：Sv 越高，积分获取加成越大。
3. 积分反哺成长：商城可兑补签卡、经验加速卡等，**不直接出售等级或额外永久发布次数**。
4. 付费会员：展示期/发布次数仍走会员规则；积分/经验仅加成获取速度。

## 二、经验成长体系（与根目录 txt v1.1 一致）

> **权威全文**：`小程序经验成长机制（基础版）.txt`（文件内标题为 v1.1 · 满级 26000）。本节为开发摘要，冲突时以 txt 为准。

### 2.1 经验获取（基础 × 角色系数）

| 行为 | 基础 EXP | 限制 |
|------|----------|------|
| 每日签到 | +5 | 每日 1 次；连续 7 天额外 +20 |
| 分享小程序 | +10 | 每日 ≤3 次 |
| 分享后好友点击 | +15 | 每日 ≤5 次；同好友每周 1 次；品牌方点击 ×1.5 |
| 分享带来新注册 | +50 | 同设备/手机号仅 1 次；品牌方 ×1.8 |

**角色系数**：普通 1.0 / 会员 1.2 / 服务商 1.3 / 品牌方 1.2  

**日上限**：签到+分享（不含拉新）合计 EXP ≤ **130**（与满勤单日约 110 接近，使 cap 有约束意义；拉新不计入）。

### 2.2 等级 Sv1～Sv13（累计 EXP · v1.1 定稿）

> **设计目标**：普通用户、**每周有效活跃 3～4 天**且当日完成签到+分享+点击满勤 → 约 **13～16 个月** 达 Sv13（不含拉新/活动额外 EXP）。会员 1.2、拉新、活动另算。  
> 阈值已与 txt v1.1 同步。

| 等级 | 累计 EXP | 本级增量 | 核心权益摘要 |
|------|----------|----------|----------------|
| Sv1 | 0 | — | 基础签到、分享 |
| Sv2 | 50 | 50 | 每月补签 1 次 |
| Sv3 | 150 | 100 | 分享获积分（进积分商城） |
| Sv4 | 350 | 200 | 第 1 次发布权（30 天展示）+ 实名 |
| Sv5 | 600 | 250 | 改稿资格（次数见 §5.5 会员年池，不按级累加） |
| Sv6 | 1000 | 400 | 签到双倍 EXP（+10/天）；第 2 次发布权 |
| Sv7 | 1600 | 600 | 每月 1 次推荐位展示分享 |
| Sv8 | 2400 | 800 | 每周自动补签 1 次；分享拉新 EXP×1.3 |
| Sv9 | 4200 | 1800 | 可邀请品牌方入驻 |
| Sv10 | 6800 | 2600 | 全行为 EXP×1.2；分享置顶 24h 等 |
| Sv11 | 10000 | 3200 | 每月 1 次定向 Push（分享类） |
| Sv12 | 16800 | 6800 | 年度峰会邀请等 |
| Sv13 | **26000** | 9200 | 传奇·缔造者；建议权、新功能优先等 |

**与 v1.0 原稿差异**：Sv1～Sv8 不变；**Sv9～Sv13 拉高**，满级由 15000 → **26000**。

### 2.3 普通用户发布权（硬规则）

- 最多 **2 次** 生命周期；**每年最多 1 次**。
- 第 1 次：Sv4 + 实名；第 2 次：Sv6 + 距上次发布 ≥365 天。
- 展示期：默认 30 天，随发布后达到的 Sv **自动延长**，**单项目最长 365 天**（从发布日起算）。
- 积分商城 **不得** 出售「第 3 次发布」或突破 2 次/1 年上限的商品。

### 2.4 补签卡（与积分衔接）

- 积分购买：**50 积分/张**，每月最多购 **3 张**。
- 会员：每月 **1 张免费**（与商城「会员免费兑补签」合并为同一额度，见确认清单 #3）。

### 2.5 防刷（与积分共用）

- 同设备/手机号拉新仅计 1 次；分享点击停留 ≥5 秒；分享点击 ≤20 次/日/用户。

## 三、积分机制

### 3.1 基础规则

- 单位：**积分**（整数；库内可用「分」存 1:1）。
- **日获取上限**：**300 积分/人/日**（不含运营一次性活动奖）。
- **有效期**：建议自然年有效（当年 12-31 过期上年余额）或滚动 12 个月 —— **开发前勾选 #8**。

### 3.2 积分获取（与经验并行触发）

| 行为 | 基础积分 | 限制 | 角色系数 |
|------|----------|------|----------|
| 每日签到 | +3 | 1 次/日 | 同经验 |
| 连续签到 7 天 | +15 | 每连续周期 1 次 | 同经验 |
| 分享小程序 | +5 | 3 次/日 | 同经验 |
| 好友点击分享 | +8 | 5 次/日；同好友每周 1 次 | 品牌 ×1.5 |
| 分享带来新注册 | +30 | 同设备/手机号 1 次 | 品牌 ×1.8 |
| 完成实名 | +100 | 终身 1 次 | 1.0 |
| 首次发布审核通过 | +200 | 每用户最多 2 次 | 按角色 |

**Sv 积分加成**（在角色系数之后再乘）：

| Sv | 加成 |
|----|------|
| Sv1～Sv2 | 0% |
| Sv3～Sv5 | +5% |
| Sv6～Sv8 | +10% |
| Sv9～Sv11 | +15% |
| Sv12～Sv13 | +20% |

公式：`最终积分 = floor(基础积分 × 角色系数 × (1 + Sv加成))`

### 3.3 积分消耗（非商城）

| 场景 | 消耗 |
|------|------|
| 购买补签卡 | 50 积分/张（月购 ≤3，先扣会员免费额度） |
| 商城兑换 | 按 SKU |
| 会员续费抵扣 | 二期可选 |

## 四、积分商城（C 端 + 后台）

### 4.1 统一入口

| 入口 | 说明 |
|------|------|
| 个人中心 | 主入口「积分商城」+ 余额 |
| 签到/成长页 | 「赚积分」「去兑换」 |
| 会员中心 | 「会员专享兑换」Tab |
| Sv3 达成 | 首次引导弹窗 |
| 站内信 | 兑换成功、积分即将过期 |

**小程序页面建议**

- `pages/growth/checkin` — 签到 + 成长概览 + 积分余额
- `pages/points/mall` — 商城首页
- `pages/points/detail` — 商品详情
- `pages/points/orders` — 兑换记录

### 4.2 商品分类（基础版 SKU）

**A. 成长辅助**

| SKU | 积分价 | 限制 |
|-----|--------|------|
| 补签卡 ×1 | 50 | 月购 ≤3；会员先扣免费 1 张/月 |
| 经验加速卡 24h | 80 | 月兑 ≤2；期间行为 EXP +20% |
| 分享加成卡 24h | 60 | 月兑 ≤2；期间分享 EXP +30% |

**B. 发布/展示（慎售，服务端强校验）**

| SKU | 积分价 | 限制 |
|-----|--------|------|
| 临时置顶卡 24h | 200 | 月兑 ≤1 |
| 展示期延长券 +30 天 | 300 | 每项目 1 次；`expire_at = min(发布日+365, 当前+30)` |
| 内容修改机会券 | 500 | **暂缓/ P2**；若上架须明确是否增加「首页品牌」池额度（见产品确认 #2 修订） |

**C. 小礼品（Sv3）** — 电子徽章/头像框等 100～300 积分

**D. 会员专享** — 免费补签 1 次/月（与 8.2 合并）、分享模板 7 天等

**E. 角色专享** — 按后台用户群体标签可见/专享价

### 4.3 兑换流程

选品 → 校验（余额、等级、角色、月限、会员）→ 扣积分（事务）→ 写 `point_orders` → 发券 `user_coupons` → 通知。

## 五、与会员/发布/群体的关系（含已拍板 #1～#6）

> 全文：`docs/成长积分-产品确认记录.md`

1. **付费会员（V6/V8）**：`member-active` 到期降级逻辑保持不变；发布/365 天走会员规则，不被积分替代。
2. **体验者**：经验/积分系数 **×1.0**（与「已拍板 #4」一致）。
3. **系数解析**：`resolveGrowthCoefficient(user)` ← 会员状态 + 后台标签 + 企业认证。
4. **发布校验**：**仅**通过 `getPublishBlockMessage`（或唯一入口）校验 Sv、实名、终身 2 次、**1 年 1 次**、活动券；**商城不得售第 3 次发布**。
5. **展示期**：`computeProjectExpireAt(project, user)` 统一计算；**覆盖** db 内「发布 +1 年」；延长券 **`min(发布日+365, 当前 expire+30)`**。
6. **内容修改（首页品牌）**：`pool_type=homepage_brand`；额度 `2×当次购买年数`；**续费新开一档、不结转**；**非会员=0**；消耗记 `source`（含 `renewal_grant`）+ `project_id`；其它板块另定。
7. **补签**：`POST /growth/checkin/makeup` 统一扣减免费额度与积分购卡。
8. **用户群体标签**：商城可见性、专享价、站内信 —— 对接 `好时机用户群体划分.txt`。

## 八、REST 接口清单

- 基础 URL：`/api`（与现网一致）

### 8.6 错误码与业务 message 建议

| code | 场景 |
|------|------|
| 400 | 参数错误、已签到、库存不足 |
| 403 | 等级不足、角色不可见商品、发布不允许 |
| 409 | 重复领取、并发兑换 |

## 附录 C：满级时长校准说明（13～16 个月）

### C.1 中活跃定义

| 项 | 假设 |
|----|------|
| 有效周 | 每周 **3～4 天** 打开并完成「满勤三件套」 |
| 满勤三件套/天 | 签到 + 分享 3 次 + 有效点击 5 次 → 基础 **110 EXP**（×角色系数前） |
| 连续 7 日签到奖 | +20；中活跃约 **每 2 周触发 1 次**（摊平约 +1.4 EXP/自然日） |
| 不含 | 拉新 +50、平台活动一次性 EXP、经验加速卡 |

### C.2 推算过程（普通用户 1.0）

| 阶段 | 累计 EXP 区间 | 日历日均 EXP（约） | 历时（约） |
|------|---------------|-------------------|------------|
| 前期 | 0 → 1000（至 Sv6 前） | 56 | 18 天 |
| 中期 | 1000 → 5000（至 Sv10 前） | 58 | 69 天 |
| 后期 | 5000 → 26000（至 Sv13） | 65～68 | 320 天 |
| **合计** | **26000** | **加权约 60** | **约 407 天 ≈ 13.6 个月** |

周均 3.5 天满勤：110×3.5 = **385 EXP/周** → 26000÷385 ≈ **67.5 周 ≈ 15.5 个月**（偏上限，未计 Sv10 后 ×1.2 与双倍签到）。

**结论**：在 3～4 天/周、不含拉新/活动前提下，**Sv13 = 26000** 落在 **约 13.5～15.5 个月**，满足 **13～16 个月** 目标。
